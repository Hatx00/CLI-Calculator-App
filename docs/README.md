# CLI Calculator v1.1

### About (English)

This project was created as part of my journey to deepen my understanding of pure C# and the .NET ecosystem.

Previously, I worked primarily with C# inside the Unity game engine. To strengthen my foundation beyond the game development environment, I decided to build a simple command-line application using .NET.

This CLI calculator is a minimal project focused on:

Reinforcing core C# fundamentals

Understanding .NET project structure

Practicing clean logic and terminal-based interaction

Working outside of a game engine context

Although it is a simple application, it represents an important step toward mastering the language at a deeper level.
***
